# ChatCinema Studio

Локальный прототип редактора вертикального видео из переписки. Состояние и ограничения: [PROGRESS.md](PROGRESS.md).

## Запуск

Нужны Node.js 24 и npm. В PowerShell:

```powershell
cd D:\Codex_Projects\ChatCinema_Studio
npm run dev
```

Откройте http://127.0.0.1:4173. Проекты сохраняются в `data/projects/<id>/project.json`, экспорт — в `data/projects/<id>/exports/`. Временные файлы рендера — в `.tmp` проекта. Остановить сервер: Ctrl+C.

В текущей рабочей копии зависимости доступны. Для новой установки предусмотрен `npm install`, но установка из сети в этой среде не была подтверждена: локальный кеш неполный, сетевой запрос не завершился. Использованные версии зафиксированы в package.json; lock-файл пока отсутствует. Remotion для рендера требует совместимый браузер и FFmpeg; на этой машине пробный рендер прошёл. Условия лицензии Remotion необходимо проверить для предполагаемого использования. Два WAV скопированы из старого проекта; права на их использование отдельно не проверены.

Проверки: `npm test`, `npm run typecheck`, `npm run build`. Сборка Vite сообщает о размере клиентского пакета и директиве Remotion; это предупреждения, не ошибки сборки.
