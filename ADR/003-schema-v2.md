# ADR 003 — схема 2 и миграция при чтении

Статус: принято для P11.1.

Единая модель Project остаётся единственным источником данных. Встроенный активный пресет дополняется ID и параметрами; отдельные сущности эмоций, групп и ресурсов хранятся в проекте. Это сохраняет существующий контракт композиции без второго представления проекта. Старые строковые эмоции и groupId становятся стабильными ID сущностей.

Хранилище проверяет старую схему строго и преобразует её в памяти, без автоматической перезаписи. Неизвестные поля отклоняются с ошибкой, чтобы не потерять данные; сохранение пользователем записывает версию 2. Блокировки проверяются на уровне команд, включая косвенные изменения таймлайна. При конфликте операция отклоняется, а не перезаписывает блок.
