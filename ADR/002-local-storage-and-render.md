# ADR 002: хранение и локальный рендер

Статус: принято для прототипа. Каждый проект сохраняется в собственной папке `data/projects/<id>`. JSON валидируется до записи и после чтения; новая версия пишется во временный файл рядом с проектом и переименовывается в целевой файл. MP4 создаётся Remotion Renderer из той же композиции и RenderPlan, что используются Player. Снимки и полноценная переносимость медиаресурсов остаются открытой работой.
