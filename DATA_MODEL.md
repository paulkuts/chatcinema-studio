# Модель данных

Схема 2 хранит один Project: ID, имя, активный ChatPreset, EmotionPreset, Asset, MessageGroup, персонажей, сообщения, независимый таймлайн, настройки видео и историю. Схемы проверяются строго: неизвестные поля не удаляются молча.

ChatPreset имеет стабильный ID, имя, фон, шрифт, цвета, радиус сообщений, признак показа имён персонажей и стандартный звук. Команды `preset.set` и `preset.update` заменяют или редактируют активный пресет. Отдельного каталога пресетов пока нет. EmotionPreset содержит ID, имя, звук (или null), строковый монтажный пресет и словарь ручных параметров; сообщение ссылается на него через `emotion`. Звук сообщения определяется сначала soundOverride, затем звуком эмоции, затем звуком чата. Монтажные параметры сохраняются, но пока не исполняются.

Asset хранит ID, имя, тип audio/video/image/gif, относительный путь без выхода за корень, MIME, теги, описание, источник, права и область application/project. Импорт и воспроизведение произвольных Asset не реализованы; существующие WAV не объявлены лицензированными.

MessageGroup имеет ID и имя, ссылка хранится в groupId сообщения. Соседние сообщения одной группы или связные через linkedToPrevious образуют накопительные состояния, по состоянию и одному звуковому событию на новое сообщение. Группы не меняют порядок или сюжетное время. Несоседние фрагменты одной группы не объединяются через промежуточные сообщения.

Сообщения и блоки имеют locked. Автоматическая команда не меняет заблокированное сообщение и не может изменить или снять блокировку блока без явного allowLocked; косвенное изменение заблокированного блока при пересчёте вызывает конфликт. Ручные изменения сообщений разрешены. История команд хранит actor, source и прежние/новые значения; автоматические побочные изменения не являются отдельными записями.

Версия 1 проверяется исходной строгой схемой, затем детерминированно преобразуется в версию 2 при чтении, без записи файла. ID, сообщения, тайминги, связи и история сохраняются; ID активного пресета выводится из ID проекта, недостающие эмоции и группы — из старых значений, блокировки выключены. Неизвестные поля и неподдерживаемые версии вызывают ошибку; сохранение в версии 2 выполняется только по обычной команде сохранения.
