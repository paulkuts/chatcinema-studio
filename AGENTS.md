# Инструкции проекта

ChatCinema Studio — самостоятельное локальное приложение. Старый проект доступен только для чтения. Сохраняйте единую модель Project, независимый таймлайн и общую Remotion-композицию для просмотра и экспорта. Ручные изменения нельзя перезаписывать молча. Изменения проходят typecheck и тесты; решения и прогресс фиксируются в документации. Рабочие и временные файлы размещаются на диске D:.
